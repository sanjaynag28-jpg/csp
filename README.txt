--------------------------------------------------------
इंस्टॉल और सेटअप करने का आसान तरीका (सिर्फ़ 1 बार)
--------------------------------------------------------
1. डाउनलोड की गई ZIP फ़ाइल को अपने कंप्यूटर में किसी पक्के फ़ोल्डर में
   Extract (अनज़िप) करें (जैसे D:\CSP-Automation या C:\CSP-Automation)।
   *ध्यान दें: इस फ़ोल्डर को बाद में कभी डिलीट या रीनेम न करें।*

2. Google Chrome ब्राउज़र खोलें और ऊपर एड्रेस बार में टाइप करें:
   chrome://extensions  (और Enter दबाएँ)

3. ऊपर दाएँ कोने में "Developer mode" का स्विच ON (चालू) करें।

4. ऊपर बाएँ कोने में "Load unpacked" बटन दबाएँ और अपना Extract किया हुआ
   फ़ोल्डर (जैसे D:\CSP-Automation) चुनें।
   (Chrome में CSP Automation Helper तुरंत जुड़ जाएगा।)

5. फ़ोल्डर के अंदर मौजूद "Setup-AutoUpdate.bat" पर 1 बार डबल-क्लिक करें।
   (इससे भविष्य में आने वाले सभी नए अपडेट आपके PC पर अपने आप लागू होंगे,
   आपको कभी दोबारा फ़ाइलें डाउनलोड करने की ज़रूरत नहीं पड़ेगी।)

6. DigiPay Web (digipayweb.csccloud.in) या DigiPay Lite (digipaylite.in) खोलें।

7. नीचे पट्टी (या पैनल) में Access Key डालें और "✓ Verify" बटन दबाएँ:
   - Access Key डालें: TEST123
   - (या यदि Admin ने आपको व्यक्तिगत Key दी है, तो वह डालें।)

--------------------------------------------------------
शॉर्टकट कीज़ (Keyboard Shortcuts)
--------------------------------------------------------
- Alt + 1        : Balance Enquiry टैब खोलें
- Alt + 2        : Cash Withdrawal टैब खोलें
- Alt + Shift + P: हेल्पर पट्टी/पैनल को दिखाएँ या छुपाएँ
