## 📖 आसान इंस्टॉलेशन गाइड (सिर्फ़ 1 बार करना है)

### चरण 1: फ़ाइल अनज़िप (Extract) करें
1. ऊपर दिए गए लिंक से **`CSP-Automation-Latest.zip`** डाउनलोड करें।
2. डाउनलोड हुई ZIP फ़ाइल पर राइट-क्लिक करके **"Extract All..."** (अनज़िप) करें।
3. इसे अपने कंप्यूटर के किसी सुरक्षित फ़ोल्डर में रखें (जैसे `D:\CSP-Automation` या `C:\CSP-Automation`)।  
   *(⚠️ ध्यान दें: इस फ़ोल्डर को बाद में कभी डिलीट या रीनेम न करें)*

### चरण 2: Chrome में Extension लोड करें
1. Google Chrome खोलें और एड्रेस बार में यह लिखकर Enter दबाएँ:  
   `chrome://extensions`
2. ऊपर दाएँ कोने में **Developer mode** का बटन **ON (चालू)** करें।
3. ऊपर बाएँ कोने में **"Load unpacked"** बटन दबाएँ।
4. अपना Extract किया हुआ फ़ोल्डर (`D:\CSP-Automation`) चुनें और **Select Folder** दबाएँ।  
   *(Chrome में CSP Automation Helper जुड़ जाएगा)*

### चरण 3: ऑटो-अपडेट चालू करें (ज़रूरी)
1. फ़ोल्डर के अंदर मौजूद **`Setup-AutoUpdate.bat`** फ़ाइल पर **1 बार डबल-क्लिक** करें।  
   *(यह बैकग्राउंड ऑटो-अपडेट चालू कर देगा — आगे जब भी कोई नया फ़ीचर या सुधार आएगा, वह आपके PC पर अपने आप आ जाएगा)*

### चरण 4: DigiPay खोलें और Key वेरिफाई करें
1. **DigiPay Web** या **DigiPay Lite** में लॉगिन करें।
2. नीचे स्क्रीन पर एक्सटेंशन की पट्टी दिखेगी।
3. वहाँ Access Key बॉक्स में Key डालें: **`TEST123`** (या Admin से मिली व्यक्तिगत Key)।
4. **"✓ Verify"** बटन दबाएँ — एक्सटेंशन तुरंत सक्रिय हो जाएगा!
